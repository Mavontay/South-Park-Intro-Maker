## The SUPER MASSIVE COMPLETE Collection

Features every season's intro, countless variations, mashups, crossovers, alternate universe versions, different musical styles, SiIvaGunner-style rips, episode generator, video game credits, and SO MUCH MORE!

## 🚀 Quick Start

### Running Locally

1. **Clone or download this repository**
   ```bash
   git clone https://github.com/Mavontay/South-Park-Intro-Maker.git
   cd South-Park-Intro-Maker
   ```

2. **Open in browser**
   - Simply open `index.html` in any modern web browser
   - No server required! Pure HTML/CSS/JavaScript

3. **Start exploring!**
   - Click through the tabs to explore different sections
   - Select any intro to view lyrics and details
   - Use the Custom Generator to create unique combinations

### Using the Application

#### Navigation
- **Tabs**: Click any tab at the top to switch between sections
  - Season Intros, Variations, Mashups
  - Custom Lines, Crossovers, AU Intros
  - Styles, Custom Generator

#### Playing Intros
1. Select any intro card by clicking on it
2. View lyrics in the playback section at the bottom
3. Use playback controls (Play, Pause, Stop, Download)

#### Creating Custom Intros
1. Go to the "Custom Generator" tab
2. Select a season base
3. Choose a musical style
4. Adjust speed and pitch sliders
5. Add optional effects
6. Click "Generate Custom Intro"

#### Building Custom Lines
1. Go to the "Custom Lines" tab
2. Enter character name and custom line
3. Choose a theme/style
4. Click "Add Custom Line"
5. View and manage saved custom lines
